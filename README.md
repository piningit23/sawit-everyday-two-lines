Two lines that explain a traffic jam to a 10-year-old: a giant zipper that jammed halfway shut, then one honest sentence about what the zipper picture maps and what it leaves out.

## Run it

```sh
python3 main.py
```

It writes the two-line entry to `/output/entry.txt` (261 characters, deterministic, Python 3.13 stdlib only).
